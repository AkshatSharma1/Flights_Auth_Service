1. Create user
curl -X POST http://localhost:3001/api/v1/user/signup \
  -H "Content-Type: application/json" \
  -d '{"email": "new_user@airline.com", "password": "MySecurePassword123"}'

2. Test signin(get token)
curl -X POST http://localhost:3001/api/v1/user/signin \
  -H "Content-Type: application/json" \
  -d '{"email": "admin@airline.com", "password": "Admin123"}'

3.Token verification(isAuthenticated)
curl -v http://localhost:3001/api/v1/user/isAuthenticated \
  -H "x-access-token: <PASTE_YOUR_JWT_HERE>"
